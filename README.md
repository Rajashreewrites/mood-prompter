# Mood Prompter
A Python script that takes your current mood and generates a unique and evocative writing prompt using the Groq API

## Setup
- Create a virtual environment and activate it
- Use pip to install groq python-dotenv
- Create a .env file with your Groq API key
  
## How to use
After the setup is complete, run python mdprmptr.py and enter your current mood when the message pops up.
A unique writing prompt should appear.
